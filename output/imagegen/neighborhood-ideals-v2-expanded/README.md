# Expanded ideal SF neighborhood maps

All 18 campaign destinations plus Presidio / Presidio Heights, redesigned as much larger district maps. Generated with the built-in image_gen tool. More connected blocks, side streets and destination clusters; longer branching routes in nature areas.

**Design concepts, not implementation screenshots or ready-to-use GBA assets.** These explore architecture, landmarks, street composition and planting. Perspective, detail and geography need review before conversion.

[Offline review gallery with notes](index.html) · [Exact generation prompts and image hashes](prompts.json) · [Original concept collection](../neighborhood-ideals-v1/README.md)

Click any image to inspect it at full size. The gallery keeps notes locally where browser storage is available; export them to share.
