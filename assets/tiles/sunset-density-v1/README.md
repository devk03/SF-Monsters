# Sunset compact infill

This original SF-only baseline supports three compact homes on verified empty
lawn parcels in the existing Sunset map. The producer reuses the accepted original
connected-frontage-v3 coral and cream homes; the third is a native horizontal flip.
Neutral gray paving comes from south-park-paving-v1. No commercial image payloads
are copied into this directory.

The frozen v79 secondary sheet contains only original authored SF tiles or zeros.
Only authored SF metatile groups are included in owned-records.json. The receipt
records hashes of opaque unused legacy tables and palette banks; their bytes stay
in the private local cartridge. This baseline came from the prior controlled
post-link Sunset overlay. The next integration must compile resources normally
and prove exact ROM/ELF bindings. Draft producer tests do not establish that gate.
