# South Park paving candidate

An original sidewalk candidate for South Park only. Shared Sunset street art, palette, maps, collision and doors stay unchanged. Human quality approval is pending.

The built-in image generator supplies a new square source on an eight-pixel logical grid. Conversion samples eight by eight logical centers, quantizes only to the existing street palette indices1/2, and repeats the master into16x16. The source, exact prompt and conversion hashes remain editable and reproducible.

`baseline-v74` contains only our original compiled South Park graphics, metatiles, attributes and palettes, frozen for an independent decoded-pixel audit across native tile repacking. It contains no commercial ROM or inherited graphics.
