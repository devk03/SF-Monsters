# Original neighborhood landmark candidates

Generated with built-in imagegen; the exact prompt is `prompt.md`, and the
unchanged source atlas is `source.png`. No commercial artwork, logos or game
characters were supplied. These are original illustrative neighborhood motifs,
not claims about a particular real mansion, mural or business.

`convert_neighborhood_landmarks.py` isolates each opaque silhouette, preserves
aspect ratio, reduces to the recorded native frame and quantizes to one original
RGB555 palette with fifteen visible colors plus transparency, without dithering.
Native PNGs, indices, palette, enlarged preview and SHA-256 receipt stay together.
`native-lettering.json` supplies original editable3x5BARlettering after reduction,
replacing illegible resampled marks while retaining the generated sign silhouette.
The candidates still need actual in-game scale, collision and human review.

Intended roles: Mission mural; Potrero lookout; Pacific Heights mansion;
Outer Sunset surfboards; Marina bar sign; Noe Valley book box. Existing approved
home fronts stay intact. This pack does not assign final startup gyms or people.
