# Original Sunset pavement atlas

Built-in image generation, opaque terrain atlas. Native conversion crops the
eight cells, resamples without smoothing and encodes a shared RGB555 palette.
Derived directions rotate the authored tile indices; human review is pending.

Use case: stylized-concept. Asset type: ORIGINAL seamless 16x16-pixel GBA city terrain tile atlas for a San Francisco Sunset tile RPG. A flat opaque atlas with EXACTLY FOUR equal columns and TWO equal rows, aspect ratio 2:1, every cell a square tile, all eight tiles touch with NO gutters, NO borders, NO labels, NO margins. Entire atlas filled with pixel terrain, no transparency. Intended native atlas exactly 64x32 pixels, enlarged in crisp logical square pixels; each tile exactly 16x16 logical pixels. Top row LEFT TO RIGHT: (1) plain dark blue-gray asphalt, extremely sparse subtle one-pixel flecks, seamless on all edges; (2) north street curb: top FOUR logical pixels are pale warm-gray concrete sidewalk, one crisp dark curb/shadow edge, rest matching asphalt; (3) OUTER northwest street corner: matching sidewalk bands FOUR pixels wide along top AND left, asphalt fills lower-right, crisp L-shaped curb corner; (4) INNER northwest corner: ONLY the top-left 4x4 logical pixel corner is concrete with a small crisp curved curb edge, all remaining area matching asphalt. Bottom row LEFT TO RIGHT: (5) horizontal road lane marking: same asphalt, a centered thin GOLDEN YELLOW DOUBLE line running from left edge to right edge, each line one logical pixel thick with one asphalt pixel between, seamless; (6) crosswalk: same asphalt with three clean pale-ivory vertical bars spanning top to bottom, zebra crossing texture, seamless vertically; (7) full warm pale-gray sidewalk slab tile with understated seams at tile edges, seamless; (8) storm drain tile: same asphalt with a small dark iron rectangular grate in the middle, simple few readable slots. All asphalt backgrounds use EXACTLY the same base color and fleck scale across cells, all sidewalk colors identical across cells. SINGLE coherent shared 16-color palette, muted SF blue-gray/cool asphalt and warm concrete, dark outlines, little ivory/golden road paint. Classic straight-down tile-RPG terrain, absolutely NO isometric perspective, no buildings, people, lettering, icons, logos, photographic texture, gradients, lighting glow, antialiasing or noise. Hard pixel clusters, readable at native 16x16. The cells MUST occupy an exact edge-to-edge 4x2 grid with no separator lines. These are original pavement assets, not from any existing game.
