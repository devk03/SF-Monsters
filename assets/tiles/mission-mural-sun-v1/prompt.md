Original Mission District mural wall generated with the built-in imagegen tool, using the existing project mural sprite as a style reference. Prompt: create a distinct GBA-scale front-facing brick mural with a joyful sun, abstract flowers, leaves and orange, turquoise and magenta shapes; no faces, text, gradients, logos or antialiasing; complete wall ends and transparent background. The generated art is converted to the existing neighborhood RGB555 palette and a 64×32 sprite by `scripts/romhack/convert_mission_sun_mural.py`.
