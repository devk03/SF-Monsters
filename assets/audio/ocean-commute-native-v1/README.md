# Ocean Commute — native score candidate

This is an original sixteen-bar Outer Sunset theme with A/A2/B/A3 development
at nominal 108 BPM. Bell melody, answering pluck, root/fifth bass, major/minor
chord pads and light kick/brush/hat rhythm occupy seven native MPlay tracks.
The last phrase descends into the opening D-major motif. Stereo placement and
velocity accents keep the accompaniment below the melody.

`assets/audio/ocean-commute.json` is the editable score/mix. The native MIDI,
voice group and eight instrument waveforms are generated by
`scripts/romhack/field_music.py`. All notes and synthesized samples are original;
the sources do not copy a commercial melody or recording.

```
python3 scripts/romhack/field_music.py
python3 tests/field_music_test.py
```

The importer replaces only the hometown music development slot and its voice
group. Native MIDI conversion supplies synchronized loop jumps for every track.
Music plays through the actual Emerald MPlay engine, including ordinary battle
and menu transitions. Full soundtrack coverage and composition/instrumentation/
mix/three-loop listening approval remain required. This is an unreviewed candidate.
Original score/sample assets use the same CC BY 4.0 attribution as the project's
other original assets, to the extent licensable; generator/import code is MIT.
