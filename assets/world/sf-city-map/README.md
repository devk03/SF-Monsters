# SF geographic map candidate

Original procedural pixel art generated by `scripts/romhack/city_map_art.py`.
This is a first-slice habitat map candidate, with Outer Sunset and South Park
anchors. It does not add travel destinations or complete the sixteen-hub map.
Art and native integration approval remain pending.

The pinned geometry is DataSF **Analysis Neighborhoods**, published by the
City and County of San Francisco. The catalog map's own configuration identifies
`j2bu-swwd` as its actual geometry dataset; `p5b7-5n3h` is a visualization and its
GeoJSON endpoint currently yields null geometries. The source metadata declares
Open Data Commons Public Domain Dedication and License (PDDL).

- Catalog: https://data.sfgov.org/Geographic-Locations-and-Boundaries/Analysis-Neighborhoods/p5b7-5n3h
- Geometry: https://data.sfgov.org/resource/j2bu-swwd.geojson
- Metadata: https://data.sfgov.org/api/views/j2bu-swwd.json
- License: https://opendatacommons.org/licenses/pddl/1.0/
- Retrieved October 14, 2026. Exact source SHA256 is pinned in `plan.json`.

These census-derived analysis polygons are not official neighborhood boundaries.
They provide an illustrative land outline and park shapes. Hub anchors represent
neighborhoods, not a claim about an exact startup office address. The full city
outline includes nonplayable background areas and Treasure Island; only the two
first-slice hubs receive active region entries. North is up, Pacific west, bay east.
Street texture is illustrative, not a claim about individual street alignments.

Run `.tools/venv/bin/python scripts/romhack/city_map_art.py` to regenerate.
The 256x256 canvas uses palette indices112–159, leaving native BGbank10 for
habitat glow. Both loaders receive a full48-color RGB555 palette. Native tile
storage is a128x120 atlas; it is not the geographic layout. The Guide gets a
32x32u16 text tilemap; the regular region map gets a64x64u8 affine tilemap.
The unique atlas stays within the Guide's232-tile limit. Both maps use the same
28x15 region grid with native tile origin(+1,+2); the Guide scrolls it8pixels down.
