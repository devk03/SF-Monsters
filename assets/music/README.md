# Original tracker music

`scripts/foundation/compose_music.py` is the editable source of **Ocean Commute**,
an unreviewed Outer Sunset music candidate. It builds a four-channel MOD with
an AABA arrangement at 108 BPM: harbor-bell melody, warm bass, major/minor tide
pads and synthesized kick, brush snare and soft hat. All samples and notes are
authored for this project; no recordings or commercial game music are used.

The build generates `engine/audio/ocean_commute.mod` and plays it through the
GBA's Direct Sound mixer. Edit the note arrays, progression, samples and mix in
the source and rebuild. The track and generated sample assets use the same
CC BY 4.0 attribution as the other original game assets, to the extent licensable.

This is one musical direction candidate, not the complete neighborhood soundtrack.
Composition, instrumentation, mix, transitions and three-loop listening review
remain user approval gates. The experimental renderer uses it across all three
maps only to exercise continuous field music while graphics change.
