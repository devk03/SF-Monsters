Original Walden Yan battle-portrait candidate for the existing Cognition trial.

Built-in image generation uses our original field atlas for the established
fictional appearance and our original Scott portrait for rendering conventions.
The green jacket, ivory shirt, charcoal trousers and white sneakers carry the
field costume into battle. Pose and all game conduct are fictional.

prompt.md preserves the exact generation request. source.png is the selected
original output. palette-policy.json deliberately separates skin, ivory cloth,
green jacket, dark hair/trousers and sneaker highlights in sixteen native colors.
Conversion produces one 64x64 four-bit frame, 2048 packed bytes, a 32-byte palette
and a transparent preview. The visible figure uses a 58-pixel height/baseline62.

No photograph or commercial-game sprite is an art input. Human likeness,
pixel-art and battle-presentation approval are pending.
