native conversion commands and licensing notes are stored beside each source.
All eighteen entries are presentation candidates; pixel/outline cleanup and
user art/audio approval remain pending. Their existence does not certify parity.

All battle views use 64×64 indexed canvases with a shared sixteen-entry
RGB555 palette (index zero transparent); entrance sheets contain two frames.
Party icons use two separately authored 32×32 views in reserved groups 3–5.
These shared icon palettes simplify some intended creature colors and need
native party-screen review. This is the opening roster plus starter evolutions,
not the complete 150-entry catalog.

See each creature README for the reproducible encoding command. Original asset
licensing follows [the repository asset terms](../README.md), to the extent
licensable. Commercial engine/asset data is supplied locally and is not relicensed.
