# Courier studio scene

Optional adventure: inspect actual weather at the window, reject or correct a
cached beacon forecast, claim one capsule, rest the party and revisit after the
first gym for a stronger signal clue. This does not bypass the prototype quest.
`VAR_GIFT_UNUSED_3` (`0x40E0`, reserved for this SF quest): 0 unread window; 1 reading learned; 2 calibrated/reward pending;
3 reward claimed. A full bag keeps state 2. Bed rest does not change respawn.

All Roon dialogue is original fictional game writing, not a quotation or a claim
about his private life. The studio belongs to the player.

Historical postcard source: SFMTA, [The N Judah Turns 87!](https://www.sfmta.com/blog/n-judah-turns-87).
The article documents the October 21, 1928 opening and Sunset Tunnel connection
between downtown and the beach. The subscription/waitlist joke is fictional.

Art: assets/tiles/courier-apartment. Collision follows furniture at native size;
the door/window use the eleven-column room center. The initial exterior entrance
uses native non-animated door/fade traversal; bespoke door opening frames still
need work before the final movement/camera gate can pass.
