## What contributors can change

They can improve dialogue, original jokes, room composition, puzzle presentation,
employee casting, teams and asset briefs inside their package. They must preserve
the accepted story input, output, safe retries and SF placement. Proposed changes
to a global rule or another package's dependency go back to the story editor.

The eight gyms are required campaign content; accepting an assignment is optional
for the person approached. A submission moves through draft → editorial approval →
implementation → functional checks → user quality review, with separate evidence.
